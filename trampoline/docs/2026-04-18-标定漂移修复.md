# 标定漂移修复实施记录

## 背景

本次修复基于 `.omx/plans/ralplan-trampoline-calibration-drift-fixes.md`：

1. 竖屏/黑边/letterbox 显示时，首帧床面标定点击坐标会和原始视频帧坐标错位。
2. 手持/非固定镜头视频中，床面四边形会在几跳后因累计单应性误差漂移。

## 实现内容

### 前端标定坐标映射

- 新增 `static/js/trampoline_calibration_geometry.js`，提供无依赖纯函数：
  - `computeContainRect`
  - `displayToImagePoint`
  - `imageToDisplayPoint`
- `video_analysis.js` 的首帧绘制、点击反算、点/线/标签绘制统一使用同一套 content-rect 映射。
- 黑边点击不再生成角点，会提示用户点击视频画面内。
- 角点仍以原始首帧图像像素坐标提交给后端。

### BedTracker 保守鲁棒性

- `BedTracker` 新增追踪状态：`trusted`、`low_confidence`、`frozen`、`tracking_lost`。
- LK/RANSAC 候选 homography 更新必须通过 sanity gate：
  - tracked points / inlier ratio
  - 四边形凸性与自交检查
  - 面积变化
  - 中心位移
  - 边长比例变化
  - frame bounds 检查
- 候选不可信时不覆盖最后可信四边形和 homography，而是降置信并 freeze/lost。
- landing 仍可基于最后可信 mapping 输出低置信坐标。

### ORB / keyframe 重定位

- 使用 OpenCV ORB，无新增依赖。
- 初始化/可信更新时保存 keyframe 特征。
- 低置信或周期触发时尝试 keyframe→current ORB 匹配 + RANSAC 重定位。
- 重定位结果也必须通过同一 sanity gate；失败时保持 freeze/lost，不继续漂移。

### Overlay

- trusted：绿色床面框。
- low-confidence：黄色/橙色。
- frozen/tracking-lost：灰色/红色标签，不再显示为可信绿色框。
