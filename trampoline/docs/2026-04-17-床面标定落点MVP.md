# 床面标定落点 MVP 实施记录

## 背景

本次实现基于 `trampoline/docs/2026-04-04-平面标定&落点plan.md` 与 `.omx/plans/ralplan-trampoline-plane-calibration-landing-mvp.md`。
目标是在不重做现有跳次分割的前提下，为上传视频模式下的每个 trampoline landing 事件补充床面落点坐标、区域与置信度。

## 已实现范围

- 新增 `trampoline/bed_tracker.py`：
  - 首帧 4 角床面标定。
  - 角点/sidecar 校验。
  - LK 光流 + RANSAC 单应性逐帧更新床面四边形。
  - 像素点映射到床面物理坐标与归一化坐标。
  - `center|mid|edge|off_bed` 区域分类。
  - 低置信情况下仍输出坐标，并用 `confidence`/`confidence_factors` 表达不确定性。

- `video_processor.py`：
  - trampoline 模式读取 `<video_id>_corners.json` sidecar。
  - `BedTracker` 在每个解码帧更新，独立于 analyzer 的采样 cadence。
  - `TrampolineAnalyzer` 仍按既有采样策略处理跳次/动作。

- `trampoline/analyzer.py`：
  - 可选接收 `bed_tracker`。
  - 只在现有 `landing` 事件分支挂载 `completed_jumps[i].landing`。
  - 映射失败不会影响原有跳次结果。

- `app.py`：
  - 非 trampoline 上传流程保持上传即处理。
  - trampoline 上传变为两阶段：
    1. `/api/video/upload` 保存视频并返回首帧 base64、图像尺寸、角点顺序。
    2. `/api/video/trampoline/start` 校验角点、写 sidecar、启动子进程。
  - 支持重复 start 的基本幂等/冲突处理。

- 前端：
  - trampoline 模式上传后显示首帧四角标定 canvas。
  - 按“前左 → 前右 → 后右 → 后左”点击并预览 polygon。
  - 分析报告展示落点坐标、zone、confidence 与低置信标签。

- LLM/report 兼容：
  - `trampoline/llm_service.py` 在存在 landing 时纳入落点数据。
  - 老结果没有 `landing` 时保持兼容。

## 数据契约

`completed_jumps[i].landing` 可选，存在时形如：

```json
{
  "bed_xy_m": [2.0, 1.0],
  "norm_xy": [0.5, 0.5],
  "zone": "center",
  "dist_from_center_m": 0.0,
  "confidence": 0.67,
  "confidence_factors": {
    "tracking": 0.81,
    "ankle_visibility": 0.74,
    "bounds": 1.0
  },
  "ankle_px": [320.0, 240.0]
}
```

角点 sidecar 形如 `<video_id>_corners.json`，schema version 为 `1`，角点顺序固定为：

```json
["front_left", "front_right", "back_right", "back_left"]
```

## 已知限制 / 后续

- MVP 未实现 ORB/keyframe 漂移校正；若真实视频 spot check 发现长视频漂移明显，再作为二期增强。
- 角点顺序依赖用户理解“前左/前右/后右/后左”；后续可增加更强的 UI 图示。
- `confidence` 权重为 MVP 默认值，后续可基于真实视频样本调参。
