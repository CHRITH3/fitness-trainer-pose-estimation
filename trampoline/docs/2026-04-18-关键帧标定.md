# 蹦床关键帧标定

本次实现基于 `.omx/plans/ralplan-trampoline-keyframe-line-minimap.md`、PRD 与测试规格，目标是在不暂停后台分析、不改跳跃分割逻辑、不增加依赖的前提下，提升蹦床床面漂移修正与可视化可读性。

## 主要变更

- 前端待标定阶段支持在原视频预览/暂停/拖动后添加多个关键帧标定。
- `/api/video/trampoline/start` 兼容旧版 `corners`，并新增 `calibrations[]`，统一写入扩展 sidecar。
- `BedTracker` 可加载多个人工关键帧，并在关键帧附近按配置窗口平滑过渡到人工床面四角。
- 新增最佳努力的床面标记线检测与叠加显示：检测失败不阻塞分析，也不会覆盖人工关键帧。
- 右下落点 minimap 改为按视频尺寸自适应缩放，小画面保持边界内，高分辨率画面更清晰。

## 兼容性

- 旧的首帧 `corners` 请求仍会被规范化为单个 frame 0 calibration。
- sidecar 解析同时支持旧 schema v1 与新 schema v2。
- 落点 payload 字段保持不变；新增 marker-line 信息仅作为 `bed_info.diagnostics` 的附加诊断。
