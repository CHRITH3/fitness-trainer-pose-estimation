# 添加分腿跳动作判定

**对应 commit:** 3c5d848
**日期:** 2026-03-28

## 需求

1. 新增 Straddle（分腿跳）动作类型
2. Tuck / Pike / Straight 要求双腿并拢

## 实现

### 新指标：腿部展开比

```
leg_spread_ratio = 左右脚踝距离 / 左右髋关节距离
```

以髋宽作为归一化基准，消除相机距离和角度的影响。

### 分类逻辑

优先级：先判断分腿，再判断角度。

1. `leg_spread > 1.8` → **Straddle**（进入）
2. 已在 Straddle 且 `leg_spread > 1.4` → 保持 Straddle（滞回退出阈值）
3. `leg_spread < 1.2` → 双腿并拢，进入角度分类（Tuck/Pike/Straight）
4. `1.2 ≤ leg_spread ≤ 1.8` → 死区，保持当前状态
