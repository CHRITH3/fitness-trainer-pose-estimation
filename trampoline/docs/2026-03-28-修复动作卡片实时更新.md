# 修复动作卡片实时更新

**对应 commit:** 7dd6d68
**日期:** 2026-03-28

## 问题

视频 overlay 左上角正确显示 ACTION，但右侧 Live Statistics 面板中的 ACTION 卡片不更新。

## 根因分析

1. **JSON 保存间隔过长**：`video_processor.py` 每 60 帧才写一次中间结果 JSON，25fps 视频下约 2.4 秒更新一次，前端轮询看到的数据严重滞后。
2. **fallback 端点缺字段**：`/api/video/analyze_frame` 端点（已禁用）的 fallback 响应中不包含 `current_action` 字段，导致前端 `updateStats()` 中 `data.current_action !== undefined` 条件不满足。

## 修复内容

| 文件 | 修改 |
|------|------|
| `video_processor.py` | 蹦床模式 JSON 保存间隔从 60 帧降至 15 帧 |
| `app.py` | 在 `analyze_video_frame()` fallback 响应中添加 `current_action` 字段 |
